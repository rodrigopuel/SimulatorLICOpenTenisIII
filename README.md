# 🎾 Simulador de Chaveamento — III LIC Open de Tênis Florianópolis

Simulador interativo do chaveamento do **III LIC Open de Tênis — Florianópolis (3º Regional FCT)**, categoria **Principiante · Masculino Simples · Acima 34 anos**.

## Como usar

1. Abra o arquivo `simulador_tenis.html` no navegador (Chrome, Safari, Firefox)
2. **Classificatórios:** escolha os vencedores das 5 partidas pré-chave (Q1 a Q5)
3. **Oitavas → Quartas → Semifinal → Final:** clique no jogador que você acha que vai vencer em cada partida
4. O campeão aparece automaticamente ao final 🏆
5. Use o botão **Reiniciar** para simular um novo cenário
